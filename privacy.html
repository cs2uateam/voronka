Privacy Policy

Last updated: May 13, 2026

voronka ("we", "the service") is a personal-use analytics dashboard operated by the cs2uateam team to track our own social-media content performance across YouTube, TikTok, Instagram, and Telegram. This policy describes what data the service collects and how it is handled.

1. Who this service is for

voronka is an internal analytics tool used solely by the operator (cs2uateam) to monitor the performance of content we ourselves have published. It is not offered to end users, does not accept third-party signups, and has no public account-creation flow.

2. What data we access

Through OAuth-authorized connections to TikTok, YouTube, Instagram, and Telegram, the service reads:

  • Basic profile info of the connected account (display name, open_id, avatar) — used to confirm which account is authorized.
  • Public video metadata posted by the connected account: title, caption, publish date, thumbnail, video duration, share URL.
  • Aggregate public metrics for each video posted by the connected account: view count, like count, comment count, share count, and (where available) completion rate, reach, profile visits, and follower changes.

The service does not access private messages, direct messages, content posted by other users, or any data unrelated to the authenticated account's own posts.

3. How the data is stored

  • OAuth refresh tokens are stored encrypted at rest in a Supabase Postgres database hosted in the EU (Frankfurt).
  • Video metadata and metrics are stored in the same database and used only to render the analytics dashboard for the operator.
  • No data is shared with third parties, sold, or used for advertising.

4. How long we keep data

Because the dashboard also functions as a content archive, video metadata and metric history are retained indefinitely. OAuth tokens are kept only while the integration is active and are deleted when the operator disconnects the account or revokes access via the source platform.

5. Revocation and deletion

The operator can revoke voronka's access to any connected account at any time via the respective platform's app-permission settings (TikTok / YouTube / Instagram / Telegram). To request deletion of stored data, contact alexprofiev@gmail.com.

6. Compliance

voronka's use of TikTok APIs conforms to the TikTok API Terms of Service and the TikTok Developer Policy. Use of Google APIs (YouTube) conforms to the Google API Services User Data Policy, including the Limited Use requirements. Use of Meta APIs (Instagram) conforms to the Meta Platform Terms.

7. Contact

Questions about this policy or any data we hold: alexprofiev@gmail.com.
